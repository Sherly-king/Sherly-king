#### 🔬 My Research

My primary research interest lies in **Test-Time Adaptation (TTA)** . The goal of TTA is to adapt a pre-trained model to a new, unseen target domain using only the unlabeled test data it encounters. This is crucial for deploying AI in the wild, where data distribution can shift unexpectedly.

My work explores:
- **Online and Continual TTA:** Developing methods that can adapt in real-time and learn continuously without forgetting.
- **Source-Free Adaptation:** Adapting models when the original source data is unavailable, a common real-world constraint.
- **Robustness against Distribution Shifts:** Creating models that are resilient to various forms of data corruption and domain shifts.
